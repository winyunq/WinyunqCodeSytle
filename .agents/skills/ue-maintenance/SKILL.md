# 在现有工程中完成需求，不生成第二套工程

## 先决定落在哪里，不先假定要写代码

以用户要求的结果为终点。复用本轮已知信息；只有未知的部分才读。

* 已有数据/配置能够表达：更新原入口，不新增运行时代码或行为图。
* 已有接口能够完成：直接调用，必要时组合现有调用。
* 已有机制有错误：在错误所属处修复，不在外侧长期维护另一套补偿。
* 确有能力缺口：在原责任系统里增加小的字段/函数/扩展点，继续用原状态和执行流程。
* 新的独立职责才考虑新系统。不能把“尚未找到”或“工具不会改这个资产”当作缺少系统的证据。

这是判断顺序，不是强制打卡步骤。不要求每次新建任务报告或重复读取。不要为了证明使用了本Skill而扩大修改。

## 用现有MCP获得足够信息

`Read(query=...)`默认一个brief，同时能发现批准的数据入口和源码接口。
可直接选`overview`或`details`一次读足。现有用法用`view=uses`：这是文本位置证据，不是完整调用图。
`Read(view=project)`显示Source、Content、配置、模块和未支持的操作，不再假设Content没有价值。

Target只补缺省。显式name/path只影响本次；不需要target_id，不需要“已搜索凭证”。
数据任务优先了解主键、字段、引用和实际读取入口；内容模式下有数据命中时不为这一步重建源码索引。
源码任务需要弄清调用约定；确实涉及核验/修改实现再读code。raw仅用于需要原貌时，不能常规先读整文件。
Doxygen标记由源码格式承担；不要在结构化字段里再重复`@brief`、“参数说明”等标签。

## 以最少必要变更完成

数据：用`Write(rows=...)`按主键增改；数量多时给`import_file + mapping`，让程序读取并转换，不逐条抄进模型。
未提交的记录、字段必须保留。不存在的引用要报告，不制造占位对象、随机ID或猜默认值。重复导入应无额外变化。
现有数据资产操作不支持/编辑器离线时，停止该路径并说明具体阻碍，不改C++或蓝图绕过去。

代码：只改对应片段。允许把`return x+0;`变短，允许用已有调用替换长实现。
给普通既有类新增成员时，`Write(kind=function,new_code=一个CPP定义)`让程序同步H。不要重交整个类。
已有共享状态、队列、索引、Tick/计时器和生命周期由原所有者继续负责。不要另建一份事实并增加同步机制。
看到review_signals就针对本次新增机制核查，不等于所有循环/分配都非法；用户明确禁止的模式不能自行降级。
源码注释单独`Write(kind=comment,fields=...)`，只提交变化的字段；程序负责格式。数据搬运无需顺便补无关函数文档。

## 维护 API 网页

项目 profile 配置 `documentation` 后，使用 `Configure(action=generate_website,audience=both)` 生成网页。developer 使用 C++ 实现和头文件；user 只取按 glob/符号正则选择的公开头文件。参数、返回值和说明来自 Doxygen，代码标识保持原样。

翻译记忆保存原文、原文哈希、译文和审核状态。先读生成结果中的 missing/stale 和对应数据绑定，只补本次缺失或变化的译文，再生成用户页。通过现有 Read/Write 数据入口更新 `translation` 和 `translated_source_hash`；不得把过期译文的哈希改成新值而不核对内容。原文未变的命中直接复用，代码行号变化无需重翻译。接口规则变化时同步维护头文件说明。

写：preview后审阅需要的差异，apply已有plan。plan是修改计划，不是目标身份。
删：独立Delete；人审阅具体差异批准后才apply。不能提交空值/换名/旧工具/直接磁盘写入来绕过删除审批或锁。

## 用原问题及反例验收，而不是只验证会编译

读取实际验证结果。`not_configured`不是通过。
数据迁移核对值、ID、引用、遗漏记录、重复导入及原消费者；不以生成新表当作完成。
性能敏感的维护使用原项目可观测约束：扫描次数、集合复制、分配、事件重复等。至少检验一个结果正确但机制多余的反例。
本包便携C++的扫描/复制/缓存反例是示范，不是通用架构证明，更不是UE/UHT实测。
构建/任务验证失败时先看返回的具体断言；不得修改受信测试、权限或规则让错误实现通过。

完成后只说明实现结果、必要变更、真实验证与未验证项。需求完成即停止，不顺便造框架、重构或补无关文档。

## 能力和安全边界

JSON/CSV记录与已支持C++操作可直接运行。UE DataTable必须连接用户实际编辑器；不支持任意二进制资产、行为图、SQLite/INI写入、星际地图专有格式解码。
同一OS账号的任意Shell权限能够绕过MCP；这不是操作系统沙箱。遵守用户边界，不把绕过视为工具补全。
接口与操作细节按需看`references/OPERATIONS.md`。

## 保留已确认约束的语义

用户已确认的约束、适用条件和理由应写入对应源码对象的文档并在读取时保留。严格相等不得擅自改成近似相等，强制条件不得降为可选建议。若实现与约束冲突，报告实现偏差，不通过改写约束掩盖冲突。测试是否足够和约束是否成立是不同问题；编译通过不证明业务约束成立。
